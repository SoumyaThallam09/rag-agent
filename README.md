# Zephyr Cloud Migration Assistant

A Streamlit-based retrieval-augmented assistant for Zephyr Squad cloud migration questions. The app combines local migration notes with selected SmartBear documentation, retrieves the most relevant text, and sends that context to Groq to generate an answer.

## Project structure

```text
rag-agent/
├── app.py                    # Streamlit web application and in-memory RAG flow
├── documents/                # Local .txt files loaded into the web app
│   ├── support.txt
│   └── smartbear_documentation.txt
├── images/                   # UI assets, including the Zephyr logo
├── chroma_db/                # Persisted Chroma data generated by standalone scripts
├── chunk_documents.py        # Splits support.txt into paragraph chunks for inspection
├── create_vector_db.py       # Creates embeddings and stores them in Chroma
├── embed_documents.py       # Embedding utility script
├── ingest_docs.py            # Additional ingestion utility
├── load_documents.py         # Reserved document-loading module
├── retrieve.py               # Standalone Chroma retrieval example
├── rag.py                    # Standalone terminal-based RAG example
├── LOCAL_SETUP.md            # Windows setup and local configuration instructions
└── .gitignore                # Ignores virtual environments, secrets, and caches
```

## How the application works

1. `app.py` loads `GROQ_API_KEY` from a local `.env` file.
2. It reads every non-empty `.txt` file in `documents/`.
3. It fetches three configured SmartBear documentation pages and extracts readable text.
4. It chunks the combined content and embeds the chunks with `all-MiniLM-L6-v2`.
5. It retrieves the most relevant chunks for each question.
6. It uses Groq to generate the final migration answer and displays the supporting sources.

The Streamlit app builds its current retrieval index in memory. The checked-in `chroma_db/` directory is used by the separate scripts such as `create_vector_db.py` and `retrieve.py`; it is not required for the main UI to start.

## Quick start

See [LOCAL_SETUP.md](LOCAL_SETUP.md) for the complete Windows setup. The short version is:

```powershell
.\.venv\Scripts\Activate.ps1
pip install streamlit truststore requests numpy beautifulsoup4 python-dotenv groq sentence-transformers chromadb
streamlit run app.py
```

Open the local URL printed by Streamlit, normally `http://localhost:8501`.

## Updating the knowledge base

- Add or edit `.txt` files under `documents/`.
- Use the **Refresh Knowledge Base** button in the sidebar, or restart Streamlit.
- Keep API keys in `.env`; do not commit them.

## Standalone scripts

The scripts outside `app.py` are small experiments for chunking, embedding, Chroma ingestion, retrieval, and terminal-based RAG. Run them from the repository root so relative paths such as `documents/support.txt` and `chroma_db/` resolve correctly.
